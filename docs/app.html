What this is. The probability that a station's annual maximum sea level exceeds the level that had a 1-in-N chance per year around 2000, in that station's own datum. The project holds no DEM and no absolute elevations, so this is not a probability that any land is flooded. Rise rate and GEV scale between gauges come from a Gaussian-process interpolation; ξ is a shared GEV shape.
